# Security Policy

## Supported versions

Only the latest release of RandomMOTD Reborn is actively supported.

## Reporting a vulnerability

Please do not report security vulnerabilities through a public GitHub issue.

Instead, contact the maintainer privately through GitHub.

Please include:

- the affected RandomMOTD Reborn version
- the Minecraft and Paper versions
- steps to reproduce the issue
- relevant logs or stack traces
- proof-of-concept details, where appropriate

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.
